# Casambi (Lithernet MQTT) für Home Assistant

Casambi-Leuchten hinter einem Lithernet-Gateway in Home Assistant einrichten,
ohne YAML zu schreiben. Unit-ID eingeben, Typ wählen, fertig.

> **Status: in Arbeit.** Diese Datei ist ein Platzhalter und wird von Paket I
> geschrieben. Der vollständige Fahrplan steht in [docs/PROJEKT.md](docs/PROJEKT.md).

## Was es kann

- Dimmbare Leuchten, Leuchten mit Farbtemperatur, Units mit mehreren
  DALI-Treibern, Casambi-Gruppen, Szenen, Broadcast und Schaltausgänge
- Geführte Ersteinrichtung, die durch die Gateway-Konfiguration leitet und
  danach prüft, ob Befehle ankommen und Zustände zurückkommen
- Diagnose je Leuchte: erreichbar, Fehlercode, Steuerungsquelle
